# LBSTER: 생물학적 서열 변환 및 진화적 표현을 위한 언어 모델 🦞

`lobster`는 분자 기반 모델을 위한 "모든 것이 포함된" 언어 모델 라이브러리입니다.
* 처음부터 빠른 사전 훈련: LBSTER는 "모든 것이 포함된" 접근 방식으로 처음부터 모델을 신속하게 사전 훈련할 수 있도록 제작되었습니다. 이는 사전 훈련 데이터 혼합 및 임베딩 공간을 제어해야 하거나 새로운 사전 훈련 목표 및 미세 조정 전략을 실험하려는 경우에 가장 유용합니다.
* 실제 신약 개발을 위해 제작됨: LBSTER는 [Frey Lab: 신약 개발을 위한 기반 모델](https://ncfrey.github.io/) 및 [Prescient Design, Genentech](https://www.gene.com/scientists/our-scientists/prescient-design)의 연구 엔지니어링에서 제공하는 새로운 코드와 사전 훈련된 모델로 주기적으로 업데이트되는 살아있는 오픈 소스 라이브러리입니다. Frey Lab은 실제 치료용 분자 설계 문제를 다루며 LBSTER 모델 및 기능은 실제 신약 개발 캠페인의 요구 사항을 반영합니다.
* 통합 생태계: LBSTER는 생물학 연구를 위한 표준 라이브러리인 beignet으로 구축되었으며 다중 작업 모델링, 유도 생성 및 다중 모드 모델을 위한 모듈식 프레임워크인 cortex와 통합되었습니다.
* 개념 지원: LBSTER는 해석 가능한 서열 모델링을 위해 718개의 개념을 지원하는 개념 병목 단백질 언어 모델인 CB-LBSTER를 통해 개념을 지원합니다.
